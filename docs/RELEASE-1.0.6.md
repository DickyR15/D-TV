# D TV 1.0.6 正式版發布說明

- 發布日期：2026-11-16
- 版本：1.0.6
- Android build number：1672
- 發布型態：正式版
- 支援平台：Android／Android TV、Windows x64、macOS、iOS

## 本版主要更新

### 跨平台進階片源管理
- 進階片源清單支援跨平台拖曳排序。
- Windows、macOS、Android、iOS 使用觸控或滑鼠拖曳；Android TV 可長按遙控器確認鍵選取，再使用方向鍵調整順序。
- 排序保存在本機，重新啟動與切換本機使用者後仍保留，並納入設定備份。

### Android TV 操作與登入
- 啟動時先載入本機使用者並顯示登入頁，不必等待原生播放核心初始化完成。
- 播放核心尚未就緒時仍維持載入閘門，避免過早操作播放器。
- 管理員 PIN 驗證移出一般本機資料寫入佇列，降低被其他資料寫入卡住的機率；保留既有 HMAC 驗證強度。
- 紅果系列季別獨立於目前季的集數詳情載入；目前季無集數或載入失敗時仍可顯示其他季別資訊。

### Android TV 詳情簡介
- 詳情頁劇情簡介使用獨立捲動區域。
- 支援遙控器上下方向鍵與翻頁鍵，讓較長簡介可以完整閱讀。
- 簡介捲動不應覆蓋播放及其他詳情頁操作焦點。

### Windows 播放控制
- 底部控制列的「畫面比例」及「睡眠計時」改用圖示呈現。
- 啟用桌面小窗時允許 Windows 使用既有原生小窗流程。
- 畫面比例、睡眠計時與 PIP 控制仍依播放器狀態及平台能力顯示。

### 投放與裝置互聯
- Android 手機／平板及 Windows 新增 Google Cast（Chromecast）裝置探索及 Cast V2 播放控制。
- 原有 DLNA／UPnP 探索及投放流程保留；兩種協定在裝置清單中區分顯示。
- iOS 版移除投放入口；本版 iOS 不提供 AirPlay／Google Cast 投放功能。
- 「裝置互聯」設定說明為透過區域網路同步收藏，不是傳送目前播放中的影片。收藏同步與播放器投放是不同功能。

### iOS 雙指縮放提示
- 雙指縮放影片時，中央提示顯示縮放百分比。
- 手指放開後提示自動隱藏，縮放效果則保留。

## 四平台發布格式

| 平台 | 格式 | 備註 |
|---|---|---|
| Android／Android TV | Universal APK | ARM64、ARMv7、x86_64 |
| Windows x64 | Portable ZIP | 解壓後執行，無須安裝 |
| macOS | Universal DMG | Apple Silicon 與 Intel |
| iOS | IPA | 未簽章，需自行簽署後側載安裝 |

## 驗證紀錄
- Flutter 全套測試、標準版主要片源測試、共用 Go 核心測試：通過。
- Android Universal APK、Windows x64 Portable ZIP、macOS Universal DMG、iOS IPA：四平台建置成功。
- 四份測試附件已產出，並由使用者完成實機測試確認 OK。

## 已知限制與未納入項目
- 黃果 AI 於 2026-11-09 改版後的新介面參數、加密取流及會話失效重建，仍需取得可驗證的站點回應才能確認完整相容；不能將空播放網址診斷視為新介面已修復。
- 紅果 H.265 輔助設備方案仍屬候選方向，不列為本版已完成的功能。
- Intel Mac Skia 渲染仍需 Intel 實機驗證，不預設宣稱已完成。
- Google Cast 能否播放特定片源，仍取決於電視端能否直接存取影片網址及片源是否需要本機解密、特殊驗證或本機代理；不保證所有片源均可投放。
- iOS 投放功能依本版決議移除。
- 本文件記錄版本功能及 CI 驗證；個別型號的播放相容性仍以實際裝置測試為準。
