# D-TV 台灣繁體中文在地化規範

D-TV 面向台灣使用者。所有使用者可見的介面、提示、錯誤訊息、設定說明及診斷文字，應使用自然、易懂且一致的台灣繁體中文。

## 用語標準

| 網絡 | 網路 | 網路連線或服務 |

「推播」只用於通知；裝置之間傳送播放工作階段應稱為「傳送播放內容」或「播放交接」，避免將兩種功能混為一談。

網址與位址不可混用：網頁或媒體資源使用「網址」；區域網路、IP 或裝置位置使用「位址」。

## 程式實作原則

1. **先辨識文字用途，再轉換。** UI 標籤、錯誤訊息、提示文字與動態片源資料可以在顯示邊界轉換；API 欄位、路徑、查詢參數、簽章內容、片源 ID、作品 ID、分集 ID 及內部狀態值不得轉換。
2. **不得全域取代。** 同一個詞在 API 協定、作品名稱與 UI 標籤中可能有不同用途。請只修改已確認為使用者可見的文字。
3. **集中處理動態文字。** 來源網站回傳的標題、分類、簡介、狀態及錯誤文字，應在顯示邊界使用 `uiTraditional()` 或片源專用顯示函式；保留原始值供搜尋、比對、排序和 API 請求使用。
4. **原生核心錯誤訊息要可直接閱讀。** Go 回傳給 Flutter 的使用者可見錯誤以台灣繁體中文撰寫；Flutter 的錯誤呈現邊界再使用 `uiTraditional()` 補足外部回應文字。
5. **詞彙要符合功能語境。** 例如通知使用「推播」，播放交接使用「傳送」；媒體使用「影片」，檔案系統使用「檔案」；網路端點使用「網址」，裝置端點使用「位址」。
6. **測試要涵蓋轉換與保護。** 在 `test/ui_localization_test.dart` 加入常見用語、片源動態文字及錯誤訊息案例；並確認拉丁字串、片源識別碼和 API 參數不會被改寫。

## 程式碼審查檢查表

- [ ] 新增或修改的使用者可見文字為台灣繁體中文。
- [ ] 動態片源文字只在顯示邊界轉換，原始資料仍可供搜尋與比對。
- [ ] API 路徑、參數、簽章、ID 和內部 enum 值沒有因在地化而改變。
- [ ] 網路通知與裝置播放交接使用不同詞彙。
- [ ] 已新增或更新對應的自動化測試。
